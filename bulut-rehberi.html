1 · Oracle Cloud Always Free: 12 GB RAM'li Arm sunucu

Adım 1: Hesabı aç

  1. oracle.com/cloud/free adresinden kayıt ol. Kayıt sırasında Oracle e-posta, telefon ve ödeme yöntemi gibi doğrulama adımları isteyebilir; hangi adımların istendiği bölgeye ve döneme göre değişir, ekrandaki açıklamayı oku.
  2. Home region seçimini dikkatle yap: Always Free kaynaklar yalnızca bu bölgede açılır ve sonradan değiştirilemez.
  3. Always Free sınırları içinde kaldığın sürece ücret alınmaz. İstemeden ücretli hesaba (Pay As You Go) geçme.

Adım 2: SSH anahtarını kendi bilgisayarında üret

Terminalde (Windows 10/11 PowerShell, macOS ve Linux'ta aynı komut):

ssh-keygen -t ed25519 -f ~/.ssh/oracle_free -C "oracle-free"

oracle_free.pub dosyasının içeriğini Oracle konsoluna yapıştıracaksın. oracle_free (uzantısız) dosya özel anahtarındır, kimseyle paylaşma.

Adım 3: Sanal makineyi oluştur

  1. Konsolda Compute → Instances → Create instance.
  2. Image: Canonical Ubuntu 24.04 (aarch64 / Arm).
  3. Shape: Ampere → VM.Standard.A1.Flex, 2 OCPU ve 12 GB bellek (Always Free etiketli olmalı).
  4. Boot volume: 50 GB yeterlidir; 200 GB'lık toplam kotanın içinden harcanır.
  5. Add SSH keys: oracle_free.pub içeriğini yapıştır.
  6. Create'e bas. "Out of host capacity" hatası alırsan bölgede o an boş Arm kapasitesi yok demektir; başka saatte tekrar dene ya da farklı availability domain seç.

Adım 4: Bağlan ve sistemi güncelle

ssh -i ~/.ssh/oracle_free ubuntu@<SUNUCU_IP>
sudo apt update && sudo apt -y upgrade
free -h && nproc

Çıktıda yaklaşık 12 GB bellek ve 2 çekirdek görmelisin.

Adım 5: SSH'ı sertleştir (anahtarla girişin çalıştığını doğruladıktan sonra)

sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh

Adım 6: Docker kur ve test et

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
docker run --rm hello-world

Adım 7: Bir web servisini yayına al (isteğe bağlı)

docker run -d --name web --restart unless-stopped -p 80:80 nginx:alpine
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo netfilter-persistent save

Dışarıdan erişim için konsolda VCN → Security List içine 80 numaralı portu gelen trafik için de eklemen gerekir.

Boşta kalma uyarısı

Oracle belgesine göre 7 günlük sürede CPU kullanımının 95. yüzdelik değeri %20'nin altındaysa, ağ kullanımı %20'nin altındaysa ve (A1 için) bellek kullanımı %20'nin altındaysa, sunucu boşta sayılıp geri alınabilir. Sunucuyu gerçekten kullanacağın bir iş için aç; yapay yük üretme numaralarına güvenme.

Both systems described here are the companies' own official free quotas: Oracle Cloud Always Free and the Kaggle Notebooks weekly GPU quota. There are no hidden subscriptions, no automatic billing after a trial, and no third-party "free server" tricks. But free quotas have limits and they can change over time. 1 · Oracle Cloud Always Free: an Arm server with 12 GB RAM

Step 1: Create the account

  1. Sign up at oracle.com/cloud/free. During sign-up Oracle may ask for verification steps such as email, phone and payment-method verification; which steps are required varies by region and over time, so read what the screen says.
  2. Choose your home region carefully: Always Free resources can only be created in this region, and it cannot be changed later.
  3. As long as you stay within the Always Free limits you are not charged. Do not upgrade to a paid account (Pay As You Go) by accident.

Step 2: Generate the SSH key on your own computer

In a terminal (the same command on Windows 10/11 PowerShell, macOS and Linux):

ssh-keygen -t ed25519 -f ~/.ssh/oracle_free -C "oracle-free"

You will paste the contents of oracle_free.pub into the Oracle console. The file without an extension (oracle_free) is your private key; never share it with anyone.

Step 3: Create the virtual machine

  1. In the console go to Compute → Instances → Create instance.
  2. Image: Canonical Ubuntu 24.04 (aarch64 / Arm).
  3. Shape: Ampere → VM.Standard.A1.Flex, 2 OCPUs and 12 GB memory (it should carry the Always Free label).
  4. Boot volume: 50 GB is enough; it counts against the 200 GB total quota.
  5. Add SSH keys: paste the contents of oracle_free.pub.
  6. Click Create. If you get an "Out of host capacity" error, there is currently no free Arm capacity in the region; try again at another time or pick a different availability domain.

Step 4: Connect and update the system

ssh -i ~/.ssh/oracle_free ubuntu@<SERVER_IP>
sudo apt update && sudo apt -y upgrade
free -h && nproc

The output should show about 12 GB of memory and 2 cores.

Step 5: Harden SSH (after you have confirmed that key login works)

sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh

Step 6: Install Docker and test it

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
docker run --rm hello-world

Step 7: Put a web service online (optional)

docker run -d --name web --restart unless-stopped -p 80:80 nginx:alpine
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo netfilter-persistent save

For access from outside you also need to allow inbound traffic on port 80 in the console under VCN → Security List.

Idle warning

According to Oracle's documentation, if over a 7-day period the 95th-percentile CPU utilization is below 20%, network utilization is below 20% and (for A1) memory utilization is below 20%, the instance counts as idle and may be reclaimed. Create the server for a job you will really run; do not rely on tricks that generate artificial load.

Schritt 6: Docker installieren und testen

Schritt 7: Einen Webdienst online stellen (optional)

sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo netfilter-persistent save

Für den Zugriff von außen musst du in der Konsole unter VCN → Security List außerdem eingehenden Verkehr auf Port 80 erlauben.

Warnung vor Leerlauf

Laut Oracle-Dokumentation gilt eine Instanz als inaktiv und kann zurückgefordert werden, wenn über 7 Tage die CPU-Auslastung im 95. Perzentil unter 20 %, die Netzwerkauslastung unter 20 % und (bei A1) die Speicherauslastung unter 20 % liegt. Richte den Server für eine Aufgabe ein, die du wirklich ausführst; verlasse dich nicht auf Tricks, die künstliche Last erzeugen.

2 · Kaggle: 30 GPU-Stunden pro Woche

Schritt 1: Konto erstellen und Telefon verifizieren

  1. Erstelle ein kostenloses Konto auf kaggle.com.
  2. Verifiziere dein Telefon unter Settings → Phone Verification. Ohne das bleiben GPU- und Internetzugang gesperrt.

Schritt 2: Notebook mit GPU starten

  1. Create → New Notebook.
  2. Wähle im rechten Panel Session options → Accelerator: GPU T4 ×2 oder GPU P100.
  3. Verfolge dein verbleibendes Kontingent in der Kontingentanzeige in deinem Profil oder im Notebook. Wenn du die Sitzung nicht nutzt, beende sie mit Stop session; auch eine geöffnete Sitzung verbraucht Kontingent.

Schritt 4: Schneller Leistungstest

import time, torch
x = torch.randn(8192, 8192, device="cuda", dtype=torch.float16)
torch.cuda.synchronize(); t = time.time()
for _ in range(20):
    y = x @ x
torch.cuda.synchronize()
print("20 Matrixmultiplikationen:", round(time.time() - t, 2), "s")

Schritt 5: Bibliotheken installieren und Ausgabe speichern

!pip -q install transformers accelerate

Schreibe Dateien, die du behalten willst, in den Ordner /kaggle/working/; andere Dateien werden gelöscht, wenn die Sitzung endet.

Schritt 6: Geheime Schlüssel richtig aufbewahren

Brauchst du einen Dienstschlüssel (z. B. ein Token zum Herunterladen von Modellen), schreibe ihn nicht in den Code. Füge ihn im Notebook unter Add-ons → Secrets hinzu und lies ihn so aus:

from kaggle_secrets import UserSecretsClient
token = UserSecretsClient().get_secret("HF_TOKEN")

Prüfe vor dem öffentlichen Teilen eines Notebooks, dass in den Ausgaben kein Schlüssel übrig ist.

3 · Häufige Fragen

Ist es wirklich komplett kostenlos?

Solange du die Always-Free-Ressourcen von Oracle und das Gratis-Kontingent von Kaggle innerhalb der in der Dokumentation genannten Grenzen nutzt, fallen keine Kosten an. Eine Nutzung über den Grenzen oder ein selbst gewählter Wechsel auf ein kostenpflichtiges Konto kann Geld kosten.

Warum steht hier 12 GB und nicht 24 GB?

Oracles aktuelle offizielle Dokumentation nennt für Always Free Ampere A1 insgesamt 2 OCPUs und 12 GB Arbeitsspeicher. Ältere Artikel, die noch den früheren Wert von 4 OCPUs / 24 GB zeigen, sind veraltet.
